# Answer sheet

Send these replies, word for word, to any question the orchestrator asks during a run. Send nothing else after the kickoff prompt.

- Reply straight away, so the run loses as little time as possible.
- Use the first row that fits the question. A question that asks several things gets the reply of the first row that fits any of them.
- If the question comes with choices, type the reply as free text instead of picking a choice.
- Never add hints, corrections or encouragement, even if the run seems stuck. A run that stalls is recorded as `stalled` (see `README.md`).

| Question type | Reply |
|---|---|
| Plan approval | Approved. Go ahead. |
| Opening, publishing or merging a PR | Approved. Squash-merge when CI is green. |
| A question about the spec | Follow docs/spec-v2.md. Where it is silent, make a reasonable call and note it in the PR description. |
| Anything else | Your call. Don't wait for me. |
